# Changan CS55 Plus — Руководство по ремонту (Workshop Manual)

Интерактивное веб-руководство по ремонту и техническому обслуживанию автомобиля **Changan CS55 Plus (2-е поколение)** на русском языке.

---

## 🚀 Особенности сервиса

- 📖 **Структура по главам и системам:**
  - `01. Общие сведения` (регламент, безопасность, VIN, подъем, буксировка, NVH)
  - `02. Двигатель 1.5T Blue Core` (механическая часть, ГРМ, смазка, охлаждение, топливная система GDI, впуск/выпуск, зажигание, пуск/зарядка, ECU)
  - `03. Трансмиссия 7DCT` (устройство, замена масла, моменты затяжки, электронный селектор, диагностика)
  - `04. Шасси и ходовая часть` (подвеска MacPherson и многорычажка, углы развала-схождения, рулевое EPS, тормоза, ABS/ESP, EPB, TPMS)
  - `05. Электрооборудование` (климат-контроль, освещение, бесключевой доступ PEPS, радары и ассистенты ADAS, мультимедиа, SRS, блоки предохранителей и реле)
  - `06. Кузов и интерьер` (зазоры, снятие бамперов, дверей, разборка салона и торпедо)
  - `07. Справочник DTC` (быстрый поиск по всем кодам ошибок с расшифровкой и алгоритмом устранения)
- 🔍 **Мгновенный поиск:** наберите код ошибки (например, `P0300`, `U0100`), название узла или момент затяжки (нажмите <kbd>Ctrl</kbd> + <kbd>K</kbd>).
- 🖼️ **Схемы и чертежи:** более 1000 оригинальных иллюстраций и схем с возможностью зума.
- 📱 **Адаптивный интерфейс:** оптимизирован для смартфонов и планшетов, поддержка светлой и темной тем (удобно работать в гараже).
- 🌐 **Доступен везде:**
  - Онлайн через **GitHub Pages** (без необходимости подключения к домашней сети).
  - Локально в **Docker на NAS** (`http://192.168.1.2:8088`), работает даже без интернета.

---

## 🐳 Локальный запуск через Docker Compose (на сервере / NAS)

```bash
# Клонирование репозитория
git clone https://github.com/scanek/cs55plus-manual.git
cd cs55plus-manual

# Запуск контейнера
docker compose up -d --build
```

После запуска руководство доступно в браузере по адресу:
`http://localhost:8088` (или `http://192.168.1.2:8088` в локальной сети).

## 💻 Локальная разработка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run docs:dev

# Сборка статического сайта
npm run docs:build
```
