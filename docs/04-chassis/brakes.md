# Тормозная система и гидравлика

> **Страницы в оригинале:** 786 – 815 | **Модель:** Changan CS55 Plus (Второе поколение)

## 1. Технические характеристики

| Параметр | Значение |
| :--- | :--- |
| **Тормозная жидкость** | **DOT 4** (на гликолевой основе с высокой точкой кипения) |
| **Периодичность замены тормозной жидкости** | Каждые **40 000 км** или **2 года** |
| **Толщина накладки новой передней колодки** | **11.0 мм** |
| **Минимально допустимая толщина накладки (износ)** | **2.0 мм** |
| **Толщина нового переднего тормозного диска** | **28.0 мм** (вентилируемый) |
| **Минимально допустимая толщина диска (брак)** | **26.0 мм** |
| **Максимальное торцевое биение диска** | **0.04 мм** |
| **Толщина нового заднего тормозного диска** | **12.0 мм** (сплошной) |
| **Минимальная толщина заднего диска** | **10.0 мм** |

## 2. Моменты затяжки элементов тормозов

| Соединение | Момент затяжки (Н·м) |
| :--- | :--- |
| **Болты направляющих пальцев переднего суппорта** | **35 ± 3 Н·м** |
| **Болты крепления скобы переднего суппорта к кулаку** | **110 ± 10 Н·м** |
| **Болты направляющих пальцев заднего суппорта** | **30 ± 3 Н·м** |
| **Болты крепления скобы заднего суппорта** | **85 ± 8 Н·м** |
| **Банджо-болт тормозного шланга к суппорту** | **30 ± 3 Н·м** (новая медная шайба) |
| **Штуцер прокачки тормозов** | **12 ± 2 Н·м** |
