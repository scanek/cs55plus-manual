# Задняя многорычажная подвеска

> **Страницы в оригинале:** 716 – 745 | **Модель:** Changan CS55 Plus (Второе поколение)

## 1. Устройство многорычажной схемы

Задняя подвеска Changan CS55 Plus — полностью независимая, на продольных и поперечных рычагах:
* **Продольный рычаг (Trailing Arm):** воспринимает продольные тормозные и тяговые усилия, крепится к кузову через массивный демпфирующий сайлентблок.
* **Верхний поперечный рычаг:** регулирует развал заднего колеса при ходах подвески.
* **Нижний основной поперечный рычаг (подпружинный):** служит опорой для цилиндрической пружины подвески.
* **Нижний поперечный рычаг схождения:** оснащен эксцентриковым болтом для прецизионной регулировки угла схождения колеса.
* **Стабилизатор поперечной устойчивости:** соединяет оба кулака через стойки стабилизатора.

## 2. Моменты затяжки элементов задней подвески

| Соединение | Момент затяжки (Н·м) |
| :--- | :--- |
| **Верхнее крепление заднего амортизатора к кузову** | **45 ± 4 Н·м** |
| **Нижний болт крепления амортизатора к кулаку** | **110 ± 10 Н·м** |
| **Болт сайлентблока продольного рычага к кузову** | **120 ± 10 Н·м** |
| **Болты верхнего поперечного рычага** | **90 ± 8 Н·м** |
| **Эксцентриковый болт регулировки схождения заднего колеса** | **90 ± 8 Н·м** |
| **Гайки стоек заднего стабилизатора** | **40 ± 4 Н·м** |
