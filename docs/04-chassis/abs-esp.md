# Антиблокировочная система (ABS) и ESP 9.3

> **Страницы в оригинале:** 816 – 835 | **Модель:** Changan CS55 Plus (Второе поколение)

## 1. Функции интегрированного блока ESP

Автомобиль оснащен новейшим блоком динамической стабилизации **Bosch ESP 9.3**, который объединяет в себе функции:
* **ABS (Anti-lock Braking System):** предотвращение блокировки колес при экстренном торможении.
* **EBD (Electronic Brake-force Distribution):** электронное распределение тормозных сил между осями.
* **TCS (Traction Control System):** антипробуксовочная система тяги.
* **HHC (Hill Hold Control):** система помощи при трогании на подъеме (удержание тормозов 2 секунды).
* **HDC (Hill Descent Control):** ассистент спуска с горы с автоматическим подтормаживанием колес.
* **ROM (Roll Over Mitigation):** система предотвращения опрокидывания автомобиля.

## 2. Процедура прокачки тормозов через диагностический сканер

При замене гидроблока ESP или попадании воздуха в клапанную коробку обычная ручная прокачка педалью не способна удалить микропузырьки воздуха из внутренних полостей гидроаккумуляторов:
1. Заполните расширительный бачок свежей жидкостью **DOT 4** до горловины.
2. Подключите сканер, войдите в меню **ESP -> Специальные функции -> Прокачка гидроблока (Automated Bleed Routine)**.
3. Сканер поочередно включит гидронасос блока и электромагнитные клапаны для каждого контура (переднее левое -> переднее правое -> заднее правое -> заднее левое).
4. Механик одновременно открывает штуцер соответствующего суппорта до выхода сплошной струи тормозной жидкости без пузырьков воздуха.
