# Углы установки колес (развал-схождение) и шины

> **Страницы в оригинале:** 746 – 755 | **Модель:** Changan CS55 Plus (Второе поколение)

## 1. Заводские спецификации углов установки колес

Регулировка углов производится на специализированном 3D-стенде развал-схождения при снаряженной массе автомобиля (пустой салон, запасное колесо на месте, полный бак топлива).

| Параметр | Номинальное значение | Допустимый диапазон | Регулировка |
| :--- | :--- | :--- | :--- |
| **Переднее схождение (на колесо)** | **0°** | **-0.10° … +0.10°** | Регулируется рулевыми тягами |
| **Переднее суммарное схождение** | **0°** | **-0.20° … +0.20°** | Регулируется рулевыми тягами |
| **Передний развал (Camber)** | **-0.50° (-30')** | **-1.00° … 0°** | Конструктивный (не регулируется) |
| **Продольный наклон оси поворота (Caster)** | **+4.35° (+4°21')** | **+3.60° … +5.10°** | Задается положением подрамника |
| **Поперечный наклон оси (KPI)** | **+12.58°** | **+11.83° … +13.33°** | Конструктивный |
| **Заднее схождение (на колесо)** | **0°** | **-0.10° … +0.10°** | Регулируется эксцентриковыми болтами |
| **Задний развал (Camber)** | **-1.00° (-1°00')** | **-1.50° … -0.50°** | Регулируется эксцентриковыми болтами |

---

## 2. Параметры шин и давление в колесах

| Размерность колес | Давление (Холодная шина) | Момент затяжки колесных гаек |
| :--- | :--- | :--- |
| **225/60 R17** | **220 кПа (2.2 бар / 2.2 атм)** | **125 ± 10 Н·м** |
| **225/60 R18** | **220 кПа (2.2 бар / 2.2 атм)** | **125 ± 10 Н·м** |
| **225/55 R19** | **220 кПа (2.2 бар / 2.2 атм)** | **125 ± 10 Н·м** |
| **Компактное запасное колесо (докатка)** | **420 кПа (4.2 бар)** | **125 ± 10 Н·м** |

::: tip МОМЕНТ ЗАТЯЖКИ КОЛЕС
Затягивайте колесные гайки в перекрестном порядке в 2 этапа (первый этап 60 Н·м, второй этап **125 Н·м**). Запрещается использовать ударный пневмогайковерт для окончательной затяжки колесных гаек!
:::
