## 1. Технические характеристики

| Параметр | Значение |
| :--- | :--- |
| **Тип системы зажигания** | Индивидуальная микропроцессорная система с катушкой на каждый цилиндр (COP - Coil-on-Plug) |
| **Тип свечей зажигания** | С тонким иридиевым центральным электродом (Iridium) |
| **Калильное число свечи** | 7 (для турбированных моторов с высокой тепловой нагрузкой) |
| **Искровой зазор свечи зажигания** | **0.75 – 0.85 мм** (не регулировать механически во избежание повреждения иридиевого напыления!) |
| **Момент затяжки свечей зажигания** | **20 ± 2 Н·м** (строго на холодном моторе) |
| **Момент затяжки болтов катушек зажигания** | **10 ± 1 Н·м** |
| **Регламентный интервал замены свечей** | Каждые **30 000 – 40 000 км** пробега |

## 2. Диагностика пропусков зажигания (коды P0300 – P0304)

Если в блоке управления зафиксированы пропуски воспламенения смеси:
1. Выкрутите свечи и осмотрите изолятор: наличие черных токопроводящих дорожек («пробоев») на керамике требует одновременной замены свечи и резинового наконечника катушки.
2. Проверьте сопротивление вторичной обмотки катушки зажигания.
3. Проверьте напряжение питания (+12V) на крайних пинах разъема катушки при включенном зажигании.
