#### Спецификация компонента


| Имя | Технические характеристики |
| :--- | :--- |
| Сопротивление топливной форсунки | При комнатной температуре 1,83 Ом±5%; 1. При других температурах значение сопротивления будет превышать отклонение; 2. Требование к точности мультиметра составляет 0,01 Ом. |
| Минимальное сопротивление датчика количества масла (Поплавок находится в самой высокой точке) | (30±2) Ом |
| Максимальное сопротивление датчика количества масла (поплавок в самой нижней точке) | (260 ±3) Ом |
| Номинальное давление топливного насоса с датчиком топлива | 500 кПа |
| Топливный насос в сборе (сердечник насоса) выходной поток | Напряжение 13,5 В, давление 500 кПа, не менее 100 л/ч. |
| Номинальный объем топливного бака в сборе | 55л |
