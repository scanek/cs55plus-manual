## 1. Технические характеристики

| Параметр | Значение |
| :--- | :--- |
| **Тип системы охлаждения** | Закрытая, жидкостная, с принудительной циркуляцией и расширительным бачком |
| **Тип охлаждающей жидкости** | Высококачественный карбоксилатный антифриз (OAT, класс G12+ / G12++), готовый раствор 50/50 |
| **Температура начала кристаллизации (замерзания)** | **-40 °C** |
| **Полная емкость системы охлаждения** | **6.5 – 6.8 л** |
| **Давление открытия клапана пробки бачка** | **130 – 150 кПа (1.3 – 1.5 бар)** |
| **Начало открытия термостата** | **82 ± 2 °C** |
| **Полное открытие термостата** | **95 °C** |
| **Включение первой скорости вентилятора радиатора** | **96 °C** |
| **Включение максимальной скорости вентилятора** | **102 °C** |

## 2. Особенности конструкции

* **Двухконтурное охлаждение:** для ускоренного прогрева на холодном пуске и снижения токсичности отработавших газов блок цилиндров и головка блока охлаждаются раздельно с электронным термостатом.
* **Охлаждение турбокомпрессора:** корпус подшипников турбины включен в контур жидкостного охлаждения для предотвращения коксования масла после резкой остановки двигателя.
* **Вентилятор охлаждения:** бесщеточный электродвигатель с плавным ШИМ-управлением (PWM), плавно регулирующий обороты от 10% до 100% мощности в зависимости от температуры мотора и давления в системе кондиционера.

## 3. Заправка и удаление воздушных пробок (прокачка)

1. Установите автомобиль на горизонтальную площадку.
2. Медленно залейте готовый антифриз в расширительный бачок до отметки **MAX**.
3. Запустите двигатель и дайте ему поработать на холостых оборотах при выключенном кондиционере и регуляторе отопителя салона, установленном на максимальный обогрев (HI).
4. По мере выхода воздуха и прогрева двигателя уровень в бачке будет опускаться. Доливайте жидкость до отметки MAX.
5. Прогрейте мотор до срабатывания электровентилятора радиатора (около 96 °C).
6. Заглушите мотор, дайте ему остыть и проверьте итоговый уровень антифриза на холодную. Уровень должен находиться строго между отметками MIN и MAX.
