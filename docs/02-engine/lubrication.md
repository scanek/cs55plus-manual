## 1. Технические характеристики и заправочные объемы

| Параметр | Требование спецификации |
| :--- | :--- |
| **Рекомендуемое моторное масло** | Синтетическое масло с низкой вязкостью **SAE 0W-20** (допускается **5W-30** при высоких температурах) |
| **Класс качества по API / ACEA** | **API SP / SN Plus**, **ILSAC GF-6A** (специально для турбомоторов с прямым впрыском TGDI для защиты от LSPI) |
| **Объем заливаемого масла (сухой двигатель)** | **4.2 л** |
| **Объем при замене с масляным фильтром** | **3.8 – 4.0 л** |
| **Объем при замене без фильтра** | **3.5 л** |
| **Давление масла на холостом ходу (при 85 °C)** | **не менее 120 кПа (1.2 бар)** |
| **Давление масла при 3 000 об/мин (при 85 °C)** | **280 – 450 кПа (2.8 – 4.5 бар)** |
| **Момент затяжки масляного фильтра** | **18 ± 2 Н·м** |
| **Момент затяжки сливной пробки** | **55 ± 5 Н·м** |

## 2. Устройство системы смазки

Система смазки двигателя JL473ZQ7 — комбинированная, под давлением и разбрызгиванием:
* **Масляный насос:** шестеренчатый с внутренним зацеплением, приводится непосредственно от носка коленчатого вала.
* **Масляные форсунки охлаждения поршней (PCJ):** установлены в нижней части блока цилиндров и распыляют масло на днища поршней для интенсивного охлаждения в режиме высоких нагрузок.
* **Масляный радиатор (жидкостно-масляный теплообменник):** встроен в блок и охлаждается антифризом из контура охлаждения, поддерживая стабильную температуру масла при движении по трассе.

## 3. Процедура замены моторного масла и фильтра

1. Прогрейте двигатель до рабочей температуры (не менее 60 °C) и заглушите.
2. Поднимите автомобиль на подъемнике, снимите грязезащитный щиток моторного отсека.
3. Установите емкость для слива под сливное отверстие поддона.
4. Выкрутите сливную пробку ключом на 17 мм и полностью слейте отработанное масло (время слива не менее 10 минут).
5. С помощью чашечного съемника открутите масляный фильтр.
6. Очистите привалочную плоскость блока, смажьте резиновое уплотнительное кольцо нового фильтра свежим моторным маслом и накрутите фильтр вручную до касания прокладки, затем дотяните на 3/4 оборота (**момент 18 Н·м**).
7. Установите на сливную пробку новую медную уплотнительную шайбу и затяните пробку моментом **55 Н·м**.
8. Опустите автомобиль и залейте через горловину **3.8 литра** свежего масла 0W-20.
9. Проверьте уровень по щупу (должен находиться строго между отметками MIN и MAX), запустите двигатель на 2–3 минуты, убедитесь в погасании контрольной лампы давления масла и отсутствии подтеков.
