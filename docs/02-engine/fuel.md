## 1. Технические характеристики

| Параметр | Значение |
| :--- | :--- |
| **Тип системы впрыска** | Прямой непосредственный впрыск в цилиндры высокого давления (GDI) |
| **Рекомендуемое топливо** | Неэтилированный бензин АИ-92 (рекомендуется **АИ-95**) |
| **Объем топливного бака** | **55 литров** |
| **Давление низкотемпературного контура (в баке)** | **3.5 – 4.5 бар (350 – 450 кПа)** |
| **Рабочее давление в рампе высокого давления** | **от 40 бар (холостой ход) до 350 бар (полная нагрузка)** |
| **Привод ТНВД** | Механический от кулачка распределительного вала через роликовый толкатель |
| **Тип форсунок** | Электромагнитные, многоточечные, с оптимизированным факелом распыла |
| **Момент затяжки болтов ТНВД к ГБЦ** | **23 ± 2 Н·м** |
| **Момент затяжки штуцеров трубок высокого давления** | **30 ± 3 Н·м** |

## 2. Безопасность при работе с контуром высокого давления

::: danger ДАВЛЕНИЕ 350 БАР — СМЕРТЕЛЬНАЯ ОПАСНОСТЬ
* Струя бензина под давлением 350 бар пробивает кожу человека и вызывает мгновенный химический некроз тканей и заражение крови!
* **Категорически запрещается** ослаблять резьбовые соединения топливной рампы, ТНВД или форсунок при работающем двигателе или сразу после его остановки!
* **Порядок безопасного сброса давления:**
  1. Выньте предохранитель топливного подкачивающего насоса из блока предохранителей в моторном отсеке.
  2. Запустите двигатель и дайте ему заглохнуть от выработки топлива в рампе.
  3. Прокрутите стартер еще 5–7 секунд.
  4. Выключите зажигание и отсоедините клемму аккумулятора.
  5. При откручивании штуцеров оберните соединение плотной чистой тканью для улавливания остаточных капель бензина.
:::
