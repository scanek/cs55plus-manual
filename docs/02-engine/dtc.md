### P012800

Fault code P012800: Thermostat fault

1. Fault triggering conditions:

1. Engine water temperature during vehicle starting is between -10℃~40℃(Reference value)

2. Ambient temperature at vehicle start is greater than -10℃(Reference value)

3. No relevant faults of water temperature sensor and ambient temperature sensor

4. Vehicle in driving process(Non-idle condition)

5. Vehicle A/C blower is in off state

2. Possible fault causes:

1. Thermostat is stuck at normally open position

### None
