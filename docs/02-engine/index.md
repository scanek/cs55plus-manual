## 1. Технические характеристики двигателя

| Параметр | Значение |
| :--- | :--- |
| **Модель двигателя** | **JL473ZQ7** (семейство Changan Blue Core NE 1.5T) |
| **Тип двигателя** | Бензиновый, 4-тактный, рядный, 4-цилиндровый, с турбонаддувом и интеркулером |
| **Рабочий объем** | 1 494 см³ (1.5 л) |
| **Диаметр цилиндра × Ход поршня** | 73.0 мм × 89.2 мм |
| **Степень сжатия** | 10.5 : 1 |
| **Максимальная мощность** | 133 кВт (181 л.с.) при 5 500 об/мин |
| **Максимальный крутящий момент** | 300 Н·м в диапазоне 1 500 – 4 000 об/мин |
| **Газораспределительный механизм** | DOHC, 16 клапанов (4 клапана на цилиндр), роликовые коромысла с гидрокомпенсаторами |
| **Фазовращатели** | Двойная система изменения фаз газораспределения (DVVT) на впуске и выпуске |
| **Система питания** | Непосредственный прямой впрыск высокого давления (GDI, до 350 бар) |
| **Порядок работы цилиндров** | 1 — 3 — 4 — 2 |
| **Обороты холостого хода** | 750 ± 50 об/мин |
| **Экологический класс** | Евро-6 / China VI |

## 2. Меры предосторожности при техническом обслуживании

::: warning ПРАВИЛА ОБСЛУЖИВАНИЯ ДВИГАТЕЛЯ
* Перед проведением любых работ с электрооборудованием, датчиками или топливной системой обязательно отключите зажигание и **отсоедините отрицательную клемму аккумуляторной батареи**.
* **Топливная система прямого впрыска (GDI)** находится под экстремально высоким давлением (до 350 бар). Перед демонтажем ТНВД, топливной рампы или форсунок необходимо сбросить остаточное давление в топливной магистрали через диагностический сканер или отключением реле топливного насоса.
* Не прикасайтесь к горячим элементам выпускного коллектора, турбокомпрессора и радиатора до их полного остывания (опасность тяжелых термических ожогов).
* Запрещается открывать крышку расширительного бачка системы охлаждения на горячем двигателе во избежание выброса кипящего антифриза.
:::

## 3. Детали, подлежащие обязательной замене при каждой сборке

* Прокладка головки блока цилиндров (ГБЦ)
* Болты крепления ГБЦ (работающие на пределе текучести)
* Болт демпферного шкива коленчатого вала
* Болты крепления маховика
* Прокладка клапанной крышки
* Прокладка масляного поддона
* Прокладки впускного и выпускного коллекторов
* Передний и задний сальники коленчатого вала
* Уплотнительные медные шайбы и резиновые кольца (O-ring) топливных форсунок высокого давления
