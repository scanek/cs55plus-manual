# Выхлопная система и каталитический нейтрализатор

> **Страницы в оригинале:** 207 – 224 | **Модель:** Changan CS55 Plus (Второе поколение)

## 1. Конструкция выхлопного тракта

Выхлопная система автомобиля выполнена из нержавеющей жаропрочной стали и включает:
1. **Выпускной коллектор:** интегрирован в головку блока цилиндров (ГБЦ) с водяным охлаждением для быстрого прогрева двигателя и снижения температуры отработавших газов перед турбиной.
2. **Турбокомпрессор:** жестко смонтирован на фланце ГБЦ.
3. **Трехкомпонентный каталитический нейтрализатор (TWC):** установлен непосредственно за турбиной (Close-Coupled) для моментального выхода на рабочую температуру (350–800 °C).
4. **Сильфон (гибкая виброкомпенсирующая гофра):** гасит колебания силового агрегата и предотвращает передачу вибраций на кузов.
5. **Промежуточный резонатор и основной глушитель:** снижают низкочастотный и высокочастотный акустический шум выхлопа.

## 2. Кислородные датчики (Лямбда-зонды)

В системе выпуска установлены два кислородных датчика:
* **Передний датчик кислорода (Upstream / Sensor 1):** широкополосный датчик соотношения воздух/топливо (A/F Ratio Sensor), измеряет точный состав смеси до катализатора для замкнутого контура регулирования впрыска.
* **Задний датчик кислорода (Downstream / Sensor 2):** циркониевый триггерный датчик, контролирует эффективность дожигания токсичных газов каталитическим нейтрализатором.

| Соединение | Момент затяжки (Н·м) |
| :--- | :--- |
| **Передний датчик кислорода (Sensor 1)** | **45 ± 5 Н·м** (нанести высокотемпературную противозадирную пасту на резьбу) |
| **Задний датчик кислорода (Sensor 2)** | **45 ± 5 Н·м** |
| **Гайки крепления приемной трубы к турбине** | **45 ± 4 Н·м** (омедненные самоконтрящиеся гайки) |
| **Болты фланцевых соединений глушителя** | **35 ± 3 Н·м** |
