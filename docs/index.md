## Основные технические параметры автомобиля

| Параметр | Значение |
| :--- | :--- |
| **Модель автомобиля** | Changan CS55 Plus (Второе поколение) |
| **Двигатель** | 1.5T Blue Core (JL473ZQ7), рядный 4-цилиндровый с турбонаддувом |
| **Рабочий объем** | 1494 см³ (1.5 л) |
| **Система питания** | Непосредственный прямой впрыск топлива в цилиндры (GDI, давление до 350 бар) |
| **Трансмиссия** | 7-ступенчатая роботизированная коробка с двумя сцеплениями «мокрого» типа (7DCT) |
| **Привод** | Передний (2WD) |
| **Передняя подвеска** | Независимая, типа MacPherson со стабилизатором поперечной устойчивости |
| **Задняя подвеска** | Независимая многорычажная |
| **Тормозная система** | Дисковые вентилируемые спереди, дисковые сзади, электронный стояночный тормоз (EPB) |
| **Рулевое управление** | Реечное с электроусилителем на рулевой колонке (EPS) |
