#### Диагностический код неисправности


Диагностика DTC — это часть компонента или системы, которая проходит диагностическую проверку с помощью ПК-тестера. Обычно он включает в себя: Список терминалов


модуль управления, таблица кодов неисправностей, список потоков данных, список активных тестов, процесс диагностики DTC.


#### Диагностика признаков неисправности


Часть диагностики признаков неисправности предназначена для неисправности систем автомобиля, которую невозможно определить только путем визуального осмотра, за исключением


диагностический тест компонента или системы путем компьютерной проверки. Обычно включает проверку и подтверждение (проверка внешнего вида


таблица), таблица симптомов неисправностей и процесс диагностики неисправностей.
