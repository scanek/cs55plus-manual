## 1. Общие сведения о коробке передач

Автомобиль Changan CS55 Plus оснащается современной **7-ступенчатой преселективной роботизированной коробкой передач с двумя сцеплениями «мокрого» типа (Wet Dual Clutch Transmission — 7DCT)**.

### Ключевые преимущества конструкции:
* **Мокрые многодисковые сцепления:** диски сцепления постоянно погружены в циркулирующее масло специального состава, что гарантирует плавное смыкание, эффективный отвод тепла в городских пробках и исключает перегрев, характерный для «сухих» роботов.
* **Высокий КПД:** передача крутящего момента до 300 Н·м без потерь гидротрансформатора, время переключения передачи составляет всего 0.2 секунды.
* **Электронный селектор переключения (Shift-by-Wire):** отсутствие механического троса между селектором в салоне и коробкой передач. Все команды передаются по высокоскоростной шине CAN.

## 2. Технические характеристики трансмиссии

| Параметр | Значение |
| :--- | :--- |
| **Тип трансмиссии** | 7-ступенчатая роботизированная с двумя мокрыми сцеплениями (7WDCT) |
| **Максимальный передаваемый крутящий момент** | **300 Н·м** |
| **Привод** | Передний (2WD), с интегрированным цилиндрическим дифференциалом |
| **Спецификация трансмиссионного масла** | **BOT 351 C4 (Cassido / Castrol Dual Clutch Fluid)** |
| **Полный заправочный объем масла** | **5.3 ± 0.1 л** |
| **Периодичность регламентной замены масла** | Каждые **60 000 км** или **3 года** |
| **Температура рабочей жидкости при проверке уровня** | **40 – 50 °C** |
| **Система управления** | Электронный блок TCU, встроенный гидроблок с пропорциональными соленоидами |
