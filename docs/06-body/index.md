# Кузов и зазоры кузовных панелей

> **Страницы в оригинале:** 1555 – 1565 | **Модель:** Changan CS55 Plus (Второе поколение)

## Заводские зазоры и перепады кузовных деталей

При восстановительном кузовном ремонте и регулировке навесных элементов зазоры должны соответствовать следующим допускам:

| Сопряжение деталей | Номинальный зазор | Допустимый перепад плоскостей |
| :--- | :--- | :--- |
| **Капот — переднее крыло (слева и справа)** | **3.5 ± 0.5 мм** | **0.0 ± 0.5 мм** |
| **Передняя дверь — переднее крыло** | **3.8 ± 0.5 мм** | **-0.5 … +0.5 мм** |
| **Передняя дверь — задняя дверь** | **4.0 ± 0.5 мм** | **0.0 ± 0.5 мм** |
| **Задняя дверь — заднее крыло (боковина)** | **3.8 ± 0.5 мм** | **0.0 ± 0.5 мм** |
| **Крышка багажника — заднее крыло** | **4.0 ± 0.8 мм** | **-0.5 … +0.5 мм** |
| **Передняя фара — бампер / капот** | **3.0 ± 0.5 мм** | **0.0 ± 0.5 мм** |
| **Задний фонарь — бампер / крыло** | **3.0 ± 0.5 мм** | **0.0 ± 0.5 мм** |
