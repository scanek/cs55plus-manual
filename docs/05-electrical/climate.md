# Система вентиляции, отопления и кондиционирования (A/C)

> **Страницы в оригинале:** 865 – 920 | **Модель:** Changan CS55 Plus (Второе поколение)

## 1. Спецификация системы кондиционирования

| Параметр | Заводской норматив |
| :--- | :--- |
| **Модель компрессора кондиционера** | **6PV14** (с электромагнитной муфтой и переменной производительностью) |
| **Марка хладагента (фреона)** | **R134a** (экологически безопасный HFC) |
| **Заправочная масса хладагента** | **600 ± 20 грамм** |
| **Марка компрессорного масла** | **PAG SP10** (синтетическое полиалкиленгликолевое масло) |
| **Полный объем масла в системе** | **100 мл** |
| **Доливка масла при замене конденсера (радиатора)** | **30 мл** |
| **Доливка масла при замене испарителя салона** | **35 мл** |
| **Доливка масла при замене расширительного клапана (ТРВ)** | **30 мл** |
| **Доливка масла при замене трубок магистрали** | **20 мл** |
| **Момент затяжки болтов компрессора к двигателю** | **25 ± 2 Н·м** |

---

## 2. Порядок заправки и вакуумирования системы

1. Подключите быстросъемные адаптеры автоматической заправочной станции к сервисным портам высокого (H) и низкого (L) давления.
2. Запустите цикл рекуперации: станция откачает остатки старого фреона и отделит отработанное компрессорное масло.
3. Проведите вакуумирование системы в течение **не менее 20 минут** (глубина вакуума не менее -0.98 бар) для полного испарения влаги из контура.
4. Выполните тест на герметичность под вакуумом (выдержка 5 минут). Если давление падает — найдите утечку с помощью ультрафиолетового красителя или детектора утечек.
5. Заправьте свежее масло **PAG SP10** в объеме, равном слитому плюс компенсация замененных узлов.
6. Заправьте строго **600 грамм фреона R134a** в жидкой фазе.
7. Запустите двигатель, включите кондиционер на минимальную температуру (LO), вентилятор на 3-ю скорость. Температура воздуха из центральных дефлекторов должна опуститься до **+4 … +8 °C** в течение 3–5 минут.
